# Prototipo de rediseño

`rediseno-antidoto.html` es el prototipo publicado: dos direcciones de la home (A editorial, B expresiva) y el sistema de diseño. Es un fragmento HTML autocontenido (fotos, logos y la fuente Modulus van embebidos) que se puede abrir en un navegador.

`plantilla.html` es la fuente legible, con marcadores `{{...}}` donde van el logo, las fotos, los logos de clientes y la fuente.

El prototipo es material de exploración, no código de producción: el sitio final se construye en Astro a partir de la dirección elegida.
